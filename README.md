# 韵家口巡查工作台

本地网页和桌面应用，用于从混合的每日巡查照片生成三条线路的现场记录、附件命名、排班关联、日志草稿和路况日报。

## 日常使用

推荐直接安装桌面版。目标电脑不需要 Node.js、npm 或固定文件夹结构：

1. 安装并打开“韵家口巡查工作台”。
2. 首次使用时点击右上角登录状态，在应用内官方窗口完成正常登录和滑块验证。
3. 填写实际车辆和人员，把当天全部照片拖入照片工作区。
4. 点击“识别并自动填报”。
5. 应用会依次完成 OCR、线路/点位/并行车辆归集、规范命名、同日查重、排班、现场记录、日志新增或完全一致复用，并回读校验。

OCR 会根据每条线路首张和末张有效照片自动生成记录时段，默认向前、向后各留 5 分钟；时段仍可在提交前人工修改。提交后可在“回读核验”中抽查字段、附件和关联关系。

应用不会自动更新已有数据。同日存在不一致的排班、记录或日志时，预检会停止并显示冲突；只有完全一致的数据才会复用。

macOS ARM64 安装包：

```text
dist/韵家口巡查工作台-0.1.0-arm64.dmg
```

当前安装包未使用 Apple Developer ID 签名。首次打开如被 Gatekeeper 拦截，请在 Finder 中右键应用并选择“打开”。

## 开发运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。应用按中国标准时间读取当天的 `daily/YYMMDD` 目录；也可以直接拖入任意命名的混合图片。工作台使用水印时间、地点文字、坐标簇和同批图片路径上下文归集 G6 平安-西宁、西过境段、S101。

低置信度、重复点位和无法唯一判定的图片会进入人工核验，不会被静默写入。部分巡查可以成稿，但未确认时不会生成“全线畅通”等结论。

## 桌面安装包

目标电脑不需要安装 Node.js 或 npm。由维护者在对应系统执行：

```bash
npm install
npm run package:mac
# 或 npm run package:win
# 或 npm run package:linux
```

安装包输出到 `dist/`。Windows、macOS 和 Linux 必须分别在对应平台或 CI 中构建、签名和测试，不能从一台 macOS 电脑产出可直接运行的全部平台安装包。

桌面版会在应用内打开官方系统，并使用持久会话保存已授权用户的正常登录态。首次登录或会话失效时，仍需用户在官方页面完成其要求的滑块验证；应用不保存账号、密码或令牌，也不绕过验证码。
